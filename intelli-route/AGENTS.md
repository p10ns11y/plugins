# Intelli-route

Portable entry for hosts that read `AGENTS.md`.

The contract is [manifest.json](manifest.json). Install and limits: [README.md](README.md).

Fetch a skill body only after its id is in `loads`. Stop at four. Do not open every path.

## Decide

1. A paste or dump with no single ask goes through `control-feeder`, then classify the Feed.
2. No map, unknowns dominate, authorization is the unknown, or a multi-session effort whose route is still fog → route `empty` (`eva-emptiness` in this plugins repo).
3. a life or mission focus block, and the ask is not repo work → route `tstack` (`tstack/skills/tomato-loop/SKILL.md`).
4. Multi-step, until-done, or the same step is being redone → route `card` (`control-graph`).
5. Otherwise → route `light` (`pstack-map`, then installed pstack `poteto-mode` or the house row in `references/map.md`).
6. Add a signal only when its `when` matches, including `craft` when a settled conversation needs a spec before code, and `trust-stack` on a session lookback. An alignment name loads `aihero-map`. Fetch https://www.aihero.dev/skills.md. The Claude plugin is Claude Code only. `clt-dual-load` is a host rule. Do not paste it.
7. Emit situation, route, loads, skips, playbook, hitl, next, effort, and reason. `bin/route --signals` sets `effort` from the task before a subagent or a model slug. Then do that next step.

## Pause

Pause before secrets, production, irreversible git, CV promote, unknown authorization, and money, legal, or health acts. On that pause, emit the route and stop. Reversible edits proceed.

## Models

On Cursor, model seats stay in `~/.cursor/rules/pstack-models.mdc`. This stack does not write that file.

On every other host, use control-graph roles `fast`, `explore`, `coding`, `deep`, and `review`. Review uses a fresh context.

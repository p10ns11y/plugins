# /intelli-route (Cursor)

Same contract as the Grok command. There is no `$ARGUMENTS` placeholder. The user turn is the goal.

Read this plugin's `manifest.json`. Do not open every path. Prefer installed pstack `/poteto-mode` for the one playbook. Do not rewrite `~/.cursor/rules/pstack-models.mdc`.

A paste or dump with no single ask goes through `control-feeder` first. Then the first match wins:

1. No map, unknowns dominate, authorization is the unknown, or a multi-session effort whose route is still fog → route `empty`. Load `eva-emptiness`.
2. a life or mission focus block, and the ask is not repo work → route `tstack`. Load `tstack/skills/tomato-loop/SKILL.md`.
3. Multi-step, until-done, or the same step is being redone → route `card`. Load `control-graph`.
4. Otherwise → route `light`. Load `pstack-map`, then `/poteto-mode` or the house row.

`tstack` runs one tomato block and does not start a repo playbook.

Add a signal only when its `when` matches, including `odysseus-navigator` for a plan, architecture, or review, and `craft` when a settled conversation needs a spec before code. Stop at four loads. An alignment name loads `aihero-map`. Fetch https://www.aihero.dev/skills.md. The Claude plugin is Claude Code only. `clt-dual-load` is already a host rule. Do not paste it.

`hitl` is required for secrets, production, irreversible git, CV promote, unknown authorization, and money, legal, or health acts. On HITL, emit the table and stop.

Emit `## Intelli-route` with situation, route, loads, skips, playbook, hitl, next, effort, and reason. `effort` comes from `bin/route --signals` before a subagent or a model slug. Then do that one next step. `empty` stays on Ask when authorization is unknown. Do not pass `--always-approve` or `--yolo`.

Credit Lauren Tan / pstack MIT when a playbook runs. Do not copy pstack or skills-library files.

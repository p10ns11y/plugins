These habits are distilled from a conversation between **Lauren Tan** and **Matt Pocock** about running agent work like a professional kitchen. The talk is the source; timestamps in the plugin README point to approximate moments in that recording.

Two habits in this plugin are **house adaptations**, not claims Lauren Tan made: `scaled-verifiers` and `kitchen-time`. The README and those skills say so plainly.

**pstack** is [Lauren Tan's Cursor plugin](https://github.com/cursor/plugins/tree/main/pstack) (poteto, MIT). This repo ships **pstack-map**, which maps pstack onto house skills. It does not ship pstack itself.

Overlap by design:

| House plugin | Relationship |
|---|---|
| `trust-stack` | Earliest layer for an invariant; repeated misses move earlier. See `environment-on-repeat`. |
| `intelli-route` | Routes goals; outer-loop triggers feed the inner loop. See `events-over-timers`. |
| `pulse-memory` | Sparse, tagged pulses instead of dumps. See `findings-first`. |
| `premflow` | Capture and review ledgers. Optional after a findings review. |
| `mission-map` | Planning when the queue needs a map, not a script. |
| `pstack-map` | Playbook map when pstack is installed. |

This plugin does not merge pull requests. Landing stays a human act unless your repo's own rules say otherwise.

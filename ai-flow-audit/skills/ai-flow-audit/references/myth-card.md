# Myth card template

Use only when the claim has at least two evidence types: time, money, frontline quote, failed-task autopsy.

| Field | Draft |
|---|---|
| **Claim / myth** | `"AI will ____" / "Tool ____ saves ____"` |
| Who said or implied it (role only) | `Role / source` |
| Evidence IDs and types | `E-__` time / money / quote / autopsy |
| What the flow shows | Bounded fact in the sample window |
| Cost of believing it | hours / money / rework / attention |
| Confidence / unknowns | High / medium / low; gaps |
| Decision | Kill / keep / test / measure again |

## Confusion card (optional sibling)

| Field | Draft |
|---|---|
| Moment | At trigger / tool / handoff: `____` |
| Expected | `____` |
| Actual | `____` |
| Workaround | Manual step, side tool, wait |
| Cost signal | minutes, money, delay |
| Ask | What would make this clear or safe? |
| Next evidence | Role; ID by date |

## Writing rules

- Roles only. No personal names in the card body.
- Separate **said**, **seen**, and **inferred**.
- A candidate is not a finding until the evidence bar is met.

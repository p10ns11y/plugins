Load this plugin's `manifest.json`. Same contract as the Grok command (no `$ARGUMENTS` — use the user turn).

Prefer installed **pstack** `/poteto-mode` for the playbook. This command adds house loads around it. Do not rewrite `~/.cursor/rules/pstack-models.mdc`.

1. Dump → `control-feeder`, then one owner.
2. `pstack-map`, then `/poteto-mode` when the playbook fits.
3. Multi-step → control-graph Card. HITL on secrets, prod, irreversible git, CV, unknown auth.

# capture-sweep

1. Read new mail, calendar changes, group-chat turns and PR events since the last sweep. Read only; never send or reply.
2. One card per item: source, ask, deadline, owner. Drop noise.
3. Hand cards to **control-plane** `/feed`.
4. Admit to **mission-map** only cards that change the next Do. Never average contradictions.
5. Note the sweep time in **pulse-memory**.

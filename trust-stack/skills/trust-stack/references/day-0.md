# Day-0 card

Copy these three lines into the case workflow P1 table before any product code. P1 loads trust-stack. The case walkthrough does not get a second copy.

1. A side effect runs only from the user's latest message, behind one function and one failing test.
2. A story page may quote only an admitted pulse file, and its pull request stays a draft until you have read it.
3. Auto-merge stops at a side effect, a visibility change, or a page about your judgment.

| Hold | Layer |
|---|---|
| A side effect runs only from the latest user message | `check` |
| A story page quotes only an admitted pulse file | `guide` |
| Auto-merge stops at a side effect, a visibility change, or a page about judgment | `watch` |

A fitness check that the payload is complete does not hold the side effect. The latest user message is the intent.

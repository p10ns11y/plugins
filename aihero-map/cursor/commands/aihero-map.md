# /aihero-map (Cursor)

Load **aihero-map**. Same contract as the Grok command (no `$ARGUMENTS` — use the user turn).

1. Match one alignment name (or skip).
2. Load the house skill in that row.
3. Fetch https://www.aihero.dev/skills.md, or that row's `.md` page.
4. Do not install the Claude plugin. It is Claude Code only.
5. Do not copy AI Hero files. Credit Matt Pocock.

Emit the **Aihero-map** table.
